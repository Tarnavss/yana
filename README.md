# Yana / Arway — общий проект

Открывайте `yana/index.html` или `arway/index.html` из синхронизированной папки Google Drive. Веб-интерфейс Drive не запускает HTML как сайт. Сохраняйте структуру папок.

- `yana/` — RU, UA и EN; `arway/` — RU и EN.
- `assets/site.css` — общие стили; `assets/yana.css` и `assets/arway.css` — стили брендов.
- `assets/video/` — шесть общих видео для трёх языков и двух экранов.
- `assets/images/` — фотографии направлений и идей, а также постеры видео в WebP. `japan.webp` восстановлено из прежней версии.
- `assets/icons/` — шесть иконок преимуществ.
- `assets/logos/` — два логотипа компаний и семь логотипов партнёров. Логотип Yana остаётся SVG; остальные — PNG.

Форма заявки демонстрационная и требует подключения перед публикацией. Для двух отдельных доменов нужно подготовить отдельные пакеты с копией общих `assets` в каждом корне сайта.
